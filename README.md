# 《闲与仙人扫落花：镜花劫》

基于归鸿落雪小说《闲与仙人扫落花》制作的非商业同人互动剧情游戏。

## 上传 GitHub Pages

1. 将本文件夹中的全部文件上传到 GitHub 仓库根目录。
2. 在仓库 `Settings → Pages` 中选择 `Deploy from a branch`。
3. Branch 选择 `main`，目录选择 `/ (root)`，保存即可。

入口文件为 `index.html`，不需要安装依赖或执行构建命令。

## 操作

- 鼠标或触屏：调查、选择和推进剧情。
- 空格：推进普通对话；战斗中的踏风判定可用空格确认。
- Esc：关闭人物志或设置。
- 进度保存在当前浏览器中。

## 内容

- 六卷正文、正文大结局与全部番外，共 18 个可重历篇章
- 覆盖原著第 1—335 章：朝龙秘境、阳华云海、鬼面白目、背灯和月、镜中观花、沉曜日寒、九重魔障及番外线
- 天门情劫序章、蛟龙城调查教程与朝龙秘境轻策略战斗
- 清平峰“扫落花”因果结算与跨篇章修为、师徒默契成长
- 严格顺序解锁、篇章命簿、完成记录与本地自动存档
- 七位角色人物志、音乐设置、三种新手难度

原著及相关角色著作权归原作者所有；项目素材仅用于本次非商业游戏展示。
